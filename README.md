# Football Match Predictor

A machine learning engine for predicting football match outcomes.

## Objective

Predict the probability of:

- Home Win
- Draw
- Away Win

using historical football match data and pre-match features.

## Planned Architecture

```text
Historical Data
      ↓

      ↓

      ↓
